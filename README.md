## 🚀 시작하기

```bash
# 1. 클론 & 의존성 설치
git clone https://github.com/gghwan/MYAIEDUmvp.git
cd MYAIEDUmvp && npm install

# 2. 환경 변수 설정
cp apps/web/.env.example apps/web/.env.local
cp myai-slides-backend/.env.example myai-slides-backend/.env

# 3. DB 마이그레이션
cd myai-slides-backend && npx prisma migrate deploy && npx prisma generate

# 4. 개발 서버 실행
npm run dev              # Frontend → http://localhost:3000
cd myai-slides-backend && npm run start:dev  # Backend → http://localhost:4000
```
